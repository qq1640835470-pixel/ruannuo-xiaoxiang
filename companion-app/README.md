# 软糯小祥 · 学习生活助手 0.1

2026-10-15，本机可运行的初版；用户最新命名为软糯小祥。在桌面“xy codex”文件夹中双击“软糯小祥”打开，无需编程、租服务器或新安装运行时。

## 可以直接体验

### 动作过渡与精简界面（0.1.5）

拎起时逐步过渡到衣领抓点，松手停靠使用约280毫秒缓动；站立、拎起、坐下、悬挂和探头之间增加短时的头部对齐图像融合，落座/落地有轻微压缩回弹，表情也有短过渡。召回左侧改为平滑移动，可在移动中重新抓住。仍为图集动画，不代表已有骨骼绑定或完成Live2D。系统减少动态效果偏好会跳过这些过渡，安静模式只在主动交互时播放短过渡。

已删除品牌副标题、右上标语、侧栏底部标语、输入框下的装饰句，以及欢迎页/计划空白页的重复文案。交互提示收进辅助描述和设置，主界面保留对话、计划、必要状态和小祥。粉白背景继续保留。

### 自由拖动与组件停靠（0.1.4）

拖住小祥超过小距离后，会切换“拎起衣领”的姿势，可以移动到本软件窗口内各处。靠近输入框、页眉、导航、计划栏或任务卡片的可用边缘，出现停靠提示后松手；上缘通常坐下，下缘有空间时挂住，侧边会探头。按住Shift松手可在边缘躲藏，也能用悬浮菜单“换个姿势”切换可容纳的动作。空白处松手会落向下方可用边缘或窗口底部。侧栏“召回小祥”或聚焦角色后按Esc可回家，方向键可微调。

使用独立拎起/坐下/悬挂/探头素材，不只移动站姿图片。停靠锚点随页面与组件更新，本浏览器刷新后恢复；动态生成的卡片会等待出现再恢复锚点。位置只存本地浏览器，不采集鼠标轨迹。角色靠近输入区域时可能暂时遮住局部，可拖开或召回；悬浮菜单仅在指向或聚焦时显示。当前仍是动态2D，不等于Cubism Live2D，也不是跨其他Windows应用的系统桌宠。手机窄屏暂不显示。

### 左侧小祥（0.1.3）

左栏加入小型Q版动态2D小祥：眨眼、轻摆、鼠标方向跟随、摸头、轻拖和原创气泡；重复摸头也有不同回应。普通AI回复可摘录到气泡中，操作详情继续折叠。安静陪伴可关闭自动气泡和持续动画，偏好自动保留。鼠标互动和待机台词不调用付费API，不监测桌面外行为。支持键盘聚焦后Enter/空格互动；系统减少动态效果设置会停止持续动画。

这版采用透明表情图集与Canvas，不是已经完成的Cubism Live2D。尚缺能直接接入的Q版祥子绑定模型和对应SDK集成；来源与下一步见assets/companion-character.md。桌面侧栏已经实现，手机窄屏暂隐藏角色。

### 对话与操作记录（0.1.2）

普通正文采用自然、温柔可爱的虚拟AI女仆表达，按情境酌情称呼“主人”，不过度重复口癖。工具状态、回复来源和技术错误信息放入默认收起的“操作记录/回复信息”，展开后显示小型代码记录。打开程序仍自动处理；失败正文会简短说明，不能把已提交启动请求说成已核验窗口打开。系统朗读只读正文，不朗读操作日志。历史操作记录读取时更新显示状态，不重复执行。

### 最新交互：打开即执行（0.1.1）

明确说“打开QQ”“打开微信”“打开记事本”等，助手会直接向系统提交启动请求，不再出现待点击的确认按钮；打开已支持网页、地图和助手资料目录同样自动处理。新补充Edge、Chrome、记事本、计算器、Steam的固定安装路径支持，是否可用以本机实际发现为准。否定请求和讨论示例不自动打开；不重放历史操作，重复提交同一动作ID被阻止。失败显示失败，不称已打开。

这项偏好仅覆盖打开类动作，消息草稿不因此变成已发送，其他业务接口沿用原有范围。用户打开指令走本地路由时不调用模型。

- 自然中文对话：默认接入已有 Gemini `gemini-3.1-flash-lite`，DeepSeek `deepseek-flash`可在设置切换；清楚的打开/记任务/余额指令走本地路由，减少调用。
- 计划：添加、开始、暂停、完成、删除，本机保存并在下次打开恢复。不预填新日程，当前未启用系统定时提醒。
- 软件接入：打开已发现的微信/QQ本机程序；高德/百度地点检索；B站、美团、淘宝官方网页入口。
- 消息草稿：AI可准备包含对象与正文的本机草稿；本软件没有个人微信/QQ的消息读取、发送接口，也没有连接Codex本身的桌面控制/Gmail工具。
- API面板：三家已有加密凭据的按需余额/认证查询，带时间戳；Google余额仍未知。
- 朗读：浏览器系统语音。Fish已编写TTS适配但免费期限证据冲突，远程语音未启用。
- 对话中提出软件体验与改进意见，可由当前API整理到“暂存反馈”；明确说“反馈：……”可保留原文。左下“反馈与暂存”查看和编辑，手动决定发送给Codex。设置可导出本机数据与运行诊断。

## 试用费用

用户本次明确授权测试最多人民币10元。应用持久化试用预算，默认只在自由对话/工具规划时请求模型。每次调用先预留0.5元，有可核对token用量才用估算成本结算；超时和未知结果不自动返还预留、不自动重试或换模型。设置可随时关闭AI调用或切换本地模式。

估算依据2026-10-15读取的官方定价。Gemini按输入$0.25/百万token、输出$1.50/百万token；DeepSeek按高峰上界输入$0.30、输出$1.20。美元统一按10人民币作预算保护系数，**不是实时汇率或实际结算金额**。费用只计算本软件，其他软件使用同一密钥的消耗不包括在内。第三方调价、计费延迟或token口径可能造成差异，本机预算不能替代供应商账户限额。

单次输入最多3000字，历史最多10条/12000字，输出最多1536token。禁用联网搜索、图片生成和付费语音。0.1.6新增仅界面可见且空闲时的AI气泡请求，受下述频率及原预算约束，不安装后台监测。默认不充值、不订阅、不改变账户设置。试用预算不按天重置。

## 数据与运行

服务只监听127.0.0.1:18764，有本机会话cookie、Host/Origin检查；未开放局域网/公网。密钥继续使用原有Windows当前用户DPAPI库，仅服务端向相应官方域名解密使用，不放进网页。计划、对话、反馈存于 `%LOCALAPPDATA%/StudyLifeAssistant/companion-v01/assistant.sqlite3`，是本机明文数据，不等同于加密聊天库。

远程AI仅获得最近少量聊天、必要的用户偏好与当前任务标题，不自动读取电脑文件、个人聊天、浏览器历史或整份画像。请不要在输入框粘贴密码、密钥等凭据。

关闭窗口只关闭界面，可再次双击恢复；点设置“退出助手”关闭本地服务。不创建开机启动项，不常驻监测。电脑睡眠/关机时无法工作。移动端自适应布局不等于已部署手机App、同步或Watch通知。

源码位于本目录，运行依赖本机已存在的Codex Python和 D:/StudyLifePlan/api-hub/hub.py；目前交付给本机使用，尚非可拷到任意电脑安装的独立EXE。

## 接口扩展约定

`connectors.py` 注册类型、能力与局限；模型函数调用只产生受校验的结构化参数。`server.py`协调任务、动作和预算；`providers.py`负责HTTP和脱敏错误；`web/`为界面。不会执行模型提供的shell命令或任意URL。

动作分prepared/requested/failed：打开类动作收到明确指令后自动处理；requested代表已交给系统，不宣称页面加载、消息发送或交易成功。单个动作ID不重复提交；外发和付款尚无执行器。后续接入沿用同一动作协议，先增加真实授权和可核对返回。

官方接口证据见上级 connector-evidence-2026-10-15.md。实际验收和本次调用记录见 QA.md。
