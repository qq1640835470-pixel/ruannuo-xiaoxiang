# 学习工作台第一版 · 0.3.4（2026-10-21）

## 改动与边界

在原独立学习页面内整合入口：主页突出当前学习、今日/逾期任务、继续学习、新建及已保存计划。选择任务后只展开一份工作区，集中查看课程范围、内容目标、关联资源和进度记录，并从该任务进入资源搜索与成果检验。

资源入口预填任务内容、课程、基础和关联 ID；内容超过接口长度时改用任务标题并要求核对，仍过长则留空提示。预填不执行预览、联网或模型调用。搜索依旧必须先核对关键词，再明确确认，保留原免费额度/PAYG门禁和未知回执恢复。检验复用任务 ID，隐藏无须重复填写的独立知识点栏；按任务筛选历史，并可切换回独立知识点和全局历史。其他范围的未结束测验与答案保留且明确标注。

详细模型请求/返回信息、完整资源请求 ID、较长安全说明折叠；提醒参数、计划编辑与调整按需进入。模型、所选资料、费用预览、保存和恢复入口保留，不自动授予权限。

保留计划生成/编辑/确认/历史，任务开始/暂停/继续/完成/取消/延期，实际分钟/学习记录及更正，测验生成/答案保存/评价更正/删除，动态调整、资源收藏/关联、应用内提醒与独立学习模型。

仅局部扩展 `GET /api/learning/resources?task_id=...`，按现有关联表读取任务资源，避免旧关联资源被全局最近100条限制遗漏；全局资源查询不变。无数据库结构变更、新付费行为、正文读取、AI教学、新搜索/错题/长期记忆系统或后台自主执行。

## 合成体验

在应用源码目录使用现有依赖运行：

```
python test_learning_workbench.py --ui
```

该入口在导入应用前重定向辅助存储，使用临时库与模拟服务，拒绝正式私人路径；浏览器测试拦截非本机请求。不应改用正式服务URL执行验收。

原生体验：`python test_learning_workbench.py --serve` 获取临时folder/base，再用与现有Windows运行依赖匹配的Python 3.12运行 `test_learning_system_034.py --host <folder> <base>`。所有profile和数据库保留在临时目录；结束后关闭隔离宿主并创建临时folder中的 `STOP` 文件退出服务。

操作：学习→今日任务→查看目标/关联资源→开始/暂停/继续→记录本次学习；查找更多资源先核对预填，再预览并确认；成果检验使用所选任务范围且仍确认模型。计划编辑/调整从已保存计划进入，提醒及独立资源/检验保留折叠入口。
